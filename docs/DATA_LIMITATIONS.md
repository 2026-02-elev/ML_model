# 데이터 한계

- 학습 후보는 품질 필터를 통과한 CGT 행이다. 그 필터는 물리 고장 정답이 아니다.
- `physical_fault_verified`는 모든 라벨 행에서 거짓이다. ESR/LEAK/HEAT 점수는 명령된 실험 조건 구분이다.
- INA219 전류는 없다. null을 0으로 둔 모델은 없다. ECM은 BLOCKED다.
- 전압 교정은 NOMINAL이고 진단에 CAL_NOMINAL이 있다. 셀 전압을 교정된 참값으로 쓰지 않는다.
- 관측된 셀 전압은 대략 0.8 V 이하다.
- 수집은 팩 1개, run 14개다. 테스트는 마지막 3개 run이다.
- CGT와 CGP는 다른 측정이다. 부하 강하로 옴 단위 ESR을 확정하지 않는다.
- 5 Hz 원본은 없다.
- 수명과 용량 정답이 없어 ④⑤는 DATA_INSUFFICIENT다.
- 시각은 Nano millis를 Pi 시간에 맞춘 추정이다.

## 이 저장소의 공개 범위

실측 원본과 가공 테이블의 공개 허가를 확인하지 못했다. 그래서 CGT, CGP, feature CSV, 라벨 CSV는 올리지 않았다. `examples/`는 입력 스키마를 보여 주는 합성 행이며 측정값이 아니다. 인증키, MQTT 접속 정보, 서버 주소도 포함하지 않았다.
